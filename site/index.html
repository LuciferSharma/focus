02 — Features

An app to plan the work. An extension to protect it.

App

Sessions with a promise attached

Write what you'll get done, pick a time, press start. When it ends, answer honestly: Yes, Partly or No, and how hard it was.

✓ Yes◐ Partly✕ No
Extension

Blocks the usual suspects

YouTube, Instagram, Reddit, X, Facebook, LinkedIn. Your list, your rules.

Extension

Music still plays

YouTube Music and YouTube Studio stay open, so your playlist and your channel aren't collateral damage.

App

Where the day went

Real work vs. distraction, your top apps and sites, and a heatmap of your best focus hours.

App

A timer that stays on top

A small floating widget keeps the clock in sight without stealing focus from what you're typing.

Extension

Three shortcuts worth learning

  • AltS Save every open tab to your to-do list, and close them
  • Alt⇧C Screenshot your work as proof for the session
  • AltN Open a notepad on any page
App

To-dos, sorted

Colour-coded categories. Paste a whole list and it splits it into tasks.

Extension

Gentle nudges

A heads-up when you're tab-hopping too fast, and a reminder to rest your eyes every 50 minutes.

App

Bring your own AI

One click copies a session summary to paste into ChatGPT or Claude. FocusWatch never calls an AI itself.

04 — Why it exists

Time trackers tell you where your hours went. None of them ask if you got anything done.

01 Output over hours

Three focused hours that produce nothing aren't a good day. Every session starts with what you'll deliver and ends with whether you did.

02 Friction, not a prison

Sometimes you really do need YouTube. You can unlock a site, but you have to type out why and wait. Usually that's enough to change your mind.

03 Your data is yours

No account, no cloud, no analytics. Your sessions never leave your computer, because a focus tool shouldn't be one more thing watching you.

04 Don't rebuild what works

ActivityWatch already tracks apps brilliantly. FocusWatch builds on top of it instead of reinventing it, and adds the part it's missing: accountability.

06 — Install

Up and running in about ten minutes.

You'll need Node.js, Git, and Chrome or Edge. All free.

Using Claude Code, Cursor or Codex? Open it in the folder where you want FocusWatch, paste this in, and it does the rest. It'll walk you through the one step it can't do: adding the extension to your browser.

Install FocusWatch (https://github.com/LuciferSharma/focus) on this machine. Follow these steps in order, and stop and tell me if any step fails.

1. Check prerequisites by running `node -v`, `git --version`, and `pnpm -v`.
   - Node.js must be version 20 or newer. If it is missing or too old, stop and ask me to install it from https://nodejs.org. Do not install it yourself.
   - If pnpm is missing, run `corepack enable`. If that fails, run `npm install -g pnpm`.
2. Clone the repo: `git clone https://github.com/LuciferSharma/focus.git` and `cd focus`.
3. Install dependencies: `pnpm install`.
4. Build the shared packages and the browser extension: `pnpm setup`.
   Confirm that `apps/extension/dist/manifest.json` now exists.
5. Check whether ActivityWatch is running by requesting http://127.0.0.1:5600/api/0/info.
   If it is not reachable, tell me ActivityWatch is optional but recommended, and link https://activitywatch.net.
6. On Windows, create a desktop shortcut:
   `powershell -NoProfile -ExecutionPolicy Bypass -File launcher\Create-Desktop-Shortcut.ps1`
7. Start FocusWatch:
   - Windows: `wscript launcher\FocusWatch.vbs`
   - macOS/Linux: run `node apps/desktop/bridge-standalone.cjs` in the background, then `pnpm dev:desktop`.
8. Verify it is running: http://127.0.0.1:47777/health should return {"status":"ok",...}, and http://localhost:1420 should load.
9. You cannot load the browser extension for me, so give me these instructions with the full absolute path filled in:
   - Open chrome://extensions (or edge://extensions)
   - Turn on "Developer mode"
   - Click "Load unpacked" and select the folder <absolute path to>/focus/apps/extension/dist
   - Pin the FocusWatch icon. Its popup should show ONLINE once the app is running.

When finished, summarize what was installed, where it is, and how to start and stop FocusWatch.

  1. Download and set up

    Open a terminal (on Windows: press Win, type PowerShell, press Enter) and run:

    git clone https://github.com/LuciferSharma/focus.git
cd focus
corepack enable
pnpm install

  2. Add the extension

    Go to chrome://extensions, switch on Developer mode, click Load unpacked, and choose focus/apps/extension/dist.

    Double-click launcher/FocusWatch.vbs. The extension icon should switch to ONLINE. On Mac or Linux, see the two-line setup.

07 — Questions

Is it really free?

Yes. It's open source under the MIT licence. No trial, no paid tier, no account.

Does it send my data anywhere?

No. Everything stays on your computer. There's no server to send it to.

Does it work on Mac or Linux?

Yes, with a couple of extra terminal commands. The one-click launcher is Windows-only for now.

Can I choose which sites get blocked?

Yes. Edit the block list in the app. YouTube Music and YouTube Studio are allowed by default.

What if I genuinely need a blocked site?

Ask for a temporary unlock from the block page. Type out why, wait a few seconds, and the site opens for 5, 10 or 15 minutes.
